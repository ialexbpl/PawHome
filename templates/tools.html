Tools

Data Generator

Generate random data for all key tables. Specify the number of animal rows — other tables scale proportionally.

Can be run multiple times — data appends without conflicts.
Performance Benchmark

Run EXPLAIN ANALYZE on test queries with and without indexes at 100, 1000, and 5000 rows. Results saved to analysis/performance_results.md.

This resets the database for each volume. May take several minutes.
Export Data

Export all tables to a downloadable file.

Import Data

Import data from a JSON or XML file. Duplicate rows are skipped.

Danger Zone

Drop all existing data and reset the database schema. Dictionary tables are re-seeded, key tables become empty.
